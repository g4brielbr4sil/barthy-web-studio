# Barthy Web Studio V1

> **Status: legado.** Esta foi a primeira versão pública da Barthy Web Studio. O repositório permanece disponível apenas como registro de evolução técnica e visual e não representa mais o posicionamento atual da marca.

## Versão atual

A versão ativa está em:

[Barthy Web Studio](https://github.com/g4brielbr4sil/barthy-web-studio-v2)

## Sobre esta versão

A V1 foi o primeiro site institucional e comercial da Barthy Web Studio. Ela reuniu apresentação de serviços, projetos, processo de trabalho, formulário de orçamento e integrações configuráveis.

O projeto foi importante para validar estrutura, identidade, responsividade, formulários, temas e fluxo de publicação, mas foi substituído pela arquitetura atual.

## Tecnologias

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Material UI e Emotion
- Radix UI
- GSAP e Motion
- React Hook Form
- GitHub Actions
- Cloudflare Pages

## O que esta versão explorou

- site institucional e comercial
- temas claro e escuro
- formulários com validação e estados de erro
- integrações configuráveis
- navegação acessível
- suporte a movimento reduzido
- carregamento sob demanda
- testes de tipagem e build
- fluxo de publicação no Cloudflare Pages
