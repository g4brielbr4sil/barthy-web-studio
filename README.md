
# Barthy Web Studio

Landing page oficial da Barthy Web Studio.

## Requisitos

- Node conforme `.nvmrc`
- pnpm conforme `packageManager` no `package.json`

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

## Verificações

```bash
pnpm typecheck
pnpm build
pnpm preview
```

O build de produção é gerado em `dist/`.
