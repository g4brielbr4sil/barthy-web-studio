# Barthy Web Studio V1

> **Status: legado.** Esta foi a primeira versão pública da Barthy Web Studio e permanece disponível como registro de evolução. Ela não representa mais o posicionamento, a arquitetura de conteúdo nem a experiência atual da marca.

## Versão atual

A evolução ativa está em **Barthy Web Studio V2**:

[Ver repositório da V2](https://github.com/g4brielbr4sil/barthy-web-studio-v2)

## Sobre esta versão

A V1 foi criada como o primeiro site institucional e comercial da Barthy Web Studio. Ela reuniu apresentação de serviços, projetos, processo de trabalho, formulário de orçamento e integrações configuráveis com Hermes ou WhatsApp.

O repositório continua público porque documenta uma etapa real da evolução técnica e visual do projeto, mas não deve ser usado como referência principal da Barthy hoje.

## Tecnologias

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Material UI e Emotion
- Radix UI
- GSAP e Motion
- React Hook Form
- GitHub Actions
- Cloudflare Pages

## O que esta versão explorou

- site institucional e comercial
- temas claro e escuro
- formulários com validação e estados de erro
- integração configurável com endpoint do Hermes
- fallback por WhatsApp
- navegação acessível
- suporte a movimento reduzido
- carregamento sob demanda
- testes de tipagem e build
- fluxo de publicação no Cloudflare Pages

## V1 e V2

| V1 | V2 atual |
| --- | --- |
| apresentação comercial extensa | narrativa mais direta e orientada a produto |
| catálogo amplo de soluções | foco em posicionamento, projetos, processo e conversão |
| Material UI, Radix, GSAP e Motion | React, TypeScript, Tailwind, Anime.js e recursos visuais progressivos |
| primeira arquitetura da marca | versão preparada para o ciclo atual da BWS |
